# Correction notices

Both surfaces show the original and corrected wording and offer one-click Undo.
Undo must preserve text entered after the correction rather than overwrite it.
The extension restores the original in an empty composer after a send; this does
not retract a message already sent.

The extension notice stays visible for eight seconds, pauses while hovered,
and restarts its countdown when the pointer leaves. Dismiss closes it early.
A newer notice replaces the previous one. Desktop currently uses its configured
bubble duration and also pauses on hover.

A shared change-history panel and history/undo API depend on RQ-LEX-AGENT-LOG.
